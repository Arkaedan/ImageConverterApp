# Android Image Converter App

Build a native Android app for converting images between different formats.

Start by supporting the formats that the Android SDK has built-in support for:

- BMP
- GIF
- JPEG
- WebP
- HEIF
- AVIF

We should also support converting from SVG to one of the raster formats.

I want to use this app on my two Android devices:

- Google Pixel 10 Pro
- Samsung Galaxy Tab S9 FE

Other requirements:

- UI should be elegant an prioritise simplicity
- UI should use Material You/Material Design 3
- The code should primarily be written in Kotlin
- Stay inside the ImageConverterApp directory and use the https://github.com/Arkaedan/ImageConverterApp repo which is already cloned
- Add an AGENTS.md
- Update the README
